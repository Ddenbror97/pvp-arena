# FROSTLINE — Winter AIM ARENA (Blender)

Source and build scripts for `public/fps/models/frostline.glb` and the FROSTLINE gameplay
layout. Same pipeline as the AIM ARENA (`../map/`), whose modular kit (`arena_kit.py`) and
asset checks (`check_glb.py`) are imported and reused unchanged.

| File | Purpose |
| --- | --- |
| `layout.py` | Single source of truth for gameplay solids and spawns. Writes `src/lib/fps/frostline-layout.ts` (client + server collision) and `build/layout.json` (Blender). Every solid is mirrored across x = 0. |
| `textures.py` | Deterministic procedural PBR textures: snow, trodden snow with slush/ice/asphalt, Soviet panel concrete, PO-2 fence panels, painted steel, ice, lit-window atlas, pine, mountains, tarp, festive bulbs, spawn paint; the shared industrial set and the PVPSPINARENA banners (official logo) come from `../map/textures.py`. `lightpool()` bakes lamp light onto the ground (emissive, second UV set). |
| `frost_kit.py` | Winter dressing kinds on top of `arena_kit`: buildings (barracks, comms building, watchtower, guardhouse, shed, warehouse + loading bay), walkway/stairs/railing, PO-2 fences, containers, crates, generator, transformer, army truck, IBC totes, snow caps/drifts/icicles, festive strings, lamps, terrain, mountains, instanced pines, decorated tree. Validates the visual/collision envelope. |
| `build_frostline.py` | Blender (headless `bpy`): sections, join-by-material, linked duplicates, `--blockout`, `.blend` + `.glb` export. |
| `build.sh` | layout → textures → Blender → `check_glb.py` → `gltf-transform instance` → `meshopt` → `public/fps/models/frostline.glb`. |
| `frostline.blend` | Editable scene (textures referenced from `build/tex`, regenerated by `textures.py`). |

```bash
art/blender/frostline/build.sh             # detailed map
art/blender/frostline/build.sh --blockout  # Phase 2 grey boxes
```

## Rules the build enforces

- **Collision match.** Below 2.9 m inside the playable rectangle every dressing vertex lies
  within 6 cm of its gameplay box (no invisible walls, no visual-only cover). The one exception
  is ground snow at most 16 cm high (drifts), which is never cover. The browser spec re-checks
  the shipped GLB with rays at 1 m against every box face.
- **No depth flicker.** No two same-facing triangles share a plane (`check_glb.py` on the
  build, and again in the browser on the quantised meshopt GLB). Snow is real geometry: caps have
  no bottom and overhang 3 cm, so they never share a plane with a wall; drifts are sloped ramps
  that meet walls and the ground along lines; decals and lit windows sit at least 6 mm proud.
- **Draw calls.** One mesh per material per culling section; small buckets fold into one
  map-wide `details` mesh; 96 pines are three GPU-instanced draws.
- **Lighting.** No real-time lights: lamps, lit windows and festive bulbs are emissive, and the
  lamp light on the snow is a 512 px emissive map on the ground's second UV set.
