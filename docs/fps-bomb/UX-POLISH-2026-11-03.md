# FPS UX and Sandgate seam polish — 2026-11-03

## Changes

- Sandgate minimap, kill feed, objective prompts, round announcements and top score have transparent backgrounds. Names and icons keep local contrast shadows; no backdrop blur or added render-loop work.
- The scoreboard uses accessible shield/skull status icons and a translucent panel. Weapon silhouettes distinguish AK, M4, AWP, Karambit, HE, fire and C4. Kill events carry their actual damage source, so a later weapon switch cannot change the icon.
- Leave/Lobby navigation moves into the Escape menu for Bomb Defusal and 1v1. The existing 1v1 Practice cancellation action is preserved.
- Bomb Defusal restores the Karambit alongside any primary: 1 primary, 2 knife, 4 grenades; mouse wheel switches the first two. Slash, stab, inspect, draw delay, cooldowns, range, armour, wall occlusion and no friendly fire are server-owned. The renderer reuses both existing team viewmodels, preloads their shaders and textures, and restores the previous slot after a grenade.
- AWP reload foley is derived from the active AK recording, without pitch stretching. Mechanical cues are retimed to the existing 3.67-second tactical/empty AWP animations. Regenerate with `node scripts/fps/build-awp-reload-audio.mjs`.

## Construction root cause

The facade builder recessed wall faces 4 cm behind collision boundaries but did not extend the faces at concave joins. Looking diagonally into an inner corner missed both faces. All 25 inner joins reproduced the gap at four sampled heights, including the Police-to-A connection.

`Frame.wall` now overlaps those existing face ends by 5 cm. `seal_facade_corners.mjs` applies the same correction to the shipped compressed GLB without rebuilding textures. The repair changes 856 position vertices and retains the texture bytes, indices, non-position attributes, scene topology and triangle count. Collision, routes, doors and map selection are unchanged. The map asset URL has a new content revision.

The shipped-model regression test traces all 100 corner/height combinations using front-facing rendering geometry. Every sample is closed.

## Release

The combined release also corrects the shared grenade renderer's prediction handoff in both modes. The old code replayed the hand-release blend on confirmation, decayed its correction before drawing, and could snap large corrections to zero. The baseline browser regression reproduced a 0.674 m backward jump. The corrected handoff preserves the drawn position, bounds airborne correction speed and reconciles snapshot-first / early confirmations without duplicate meshes. Authoritative grenade physics, timing, damage and inventory are unchanged. The real-mesh harness (`node scripts/fps/bomb-harness/grenade-handoff.mjs`) passes 54 delayed-confirmation cases and three early-confirmation cases in each of Chromium and Firefox. Focused grenade/Bomb/Worker tests pass (56 tests), alongside the typecheck, lint and site build.

This change requires both deployments. Deploy the production-generated FPS Worker config first, then the production-generated app config. The old Bomb Worker normalizes knife input to rifle, so deploying only the app would restore the model without restoring authoritative melee combat. No database migration or financial setting changes are required.
